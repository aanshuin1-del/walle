"Unlinkable" means: for any probabilistic polynomial-time adversary with full access to all on-chain data, the advantage of distinguishing "withdrawal W came from deposit D1" from "W came from D2" is negligible in the security parameter, given an anonymity set of size >= K, under the assumptions in ASSUMPTIONS.md.

## Anonymity Set

The set size for a denomination is `liveSetSize[denomination]`.

`deposit` increments `liveSetSize[denomination]` by one after the commitment is inserted. `withdraw` decrements it by one after the nullifier is marked and before any ether is sent. The value is the number of notes of that denomination that have been deposited and not yet withdrawn. It is not a score. It is a count.

The unlinkability definition is conditional on the set size being at least K. K is the parameter in that sentence. This repository does not treat a small count as if it were a large one.

When `liveSetSize[denomination] < 10`:

- The contract still accepts a valid withdrawal. There is no on-chain minimum set size.
- A uniform guess among the live notes is already correct with probability `1 / liveSetSize[denomination]`, which is greater than `1/10`.
- Timing and denomination, which are residual leakages in the table above, have fewer candidates to land on. Amount fingerprinting inside one denomination is bounded by that same count, because every note in the tree has the same wei value, but the count itself may be small.
- The reference client must show the sentence `You are withdrawing from a set of N.` with that N before the withdraw button can be enabled.
- If N is less than 10, the client must also show `Anonymity set is small. Withdrawal may be linkable by timing or amount.`

The UI has to show N before withdraw because the user is the party who decides whether to publish a recipient against this set. After the transaction is broadcast, the recipient, the fee, the relayer, and the time are public, and the set they were drawn from is the set that existed at that moment. A button that submits first and prints N afterwards does not give the user that decision. The warning at 10 is a client threshold from the spec. It is not a proof that 10 is large enough for the advantage in the definition to be negligible, and it is not a claim that the contract enforces it.

## Out of Scope

- Network-level adversaries. This includes a global passive observer of IP packets, an ISP, and traffic confirmation between a broadcaster and a recipient. The definition quoted above is about an adversary with on-chain data.
- Legal and compliance questions. This document does not say whether using the contracts is lawful anywhere.
- Amount fingerprinting. Fixed denominations remove arbitrary wei amounts and remove splits. They do not remove the choice of which of the four denominations was used, and they do not remove timing. Amount fingerprinting is mitigated, not eliminated.
- The Monero bridge. `IWrappedXMRMinter` and `IShieldedPool` are interfaces only. They are not implemented in this repository.
